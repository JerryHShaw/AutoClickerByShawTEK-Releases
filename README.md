# AutoClicker by ShawTEK — Downloads

This repository hosts the installers and update files for **AutoClicker by ShawTEK**, a Windows auto clicker
that records your clicks, drags and typing and replays them, with schedules.

**To download:** open [Releases](../../releases/latest) and run `AutoClickerByShawTEK-Setup-<version>.exe`.

Installed copies of AutoClicker check this repository for updates automatically.

Each release contains:

| File | Purpose |
| --- | --- |
| `AutoClickerByShawTEK-Setup-<version>.exe` | The installer |
| `AutoClickerByShawTEK.update.json` | Update manifest read by the app (version, SHA-256, release notes) |
| `AutoClickerByShawTEK.history.txt` | Release notes of every version |

Requires Windows 10 or later and the .NET Framework 4.8.
